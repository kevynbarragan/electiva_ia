# Prompt — Requisitos no funcionales

Analiza el proyecto y los requisitos funcionales previamente identificados.

Define los requisitos no funcionales necesarios para que el sistema tenga un comportamiento adecuado.

Considera únicamente atributos relevantes para este proyecto:

* Rendimiento.
* Usabilidad.
* Seguridad.
* Integridad de datos.
* Disponibilidad.
* Mantenibilidad.
* Compatibilidad.
* Escalabilidad.
* Interpretabilidad de resultados.

Para cada requisito utiliza:

### RNF-001 — [Nombre]

**Categoría:**

**Descripción:**

El sistema debe...

**Criterio medible o verificable:**

Indica cómo se podría comprobar que se cumple.

No inventes requisitos excesivamente estrictos sin justificación.

Los requisitos deben ser realistas para un proyecto universitario.
