# Prompt — Priorización MoSCoW

Analiza todas las historias de usuario del proyecto:

**Análisis de Intención de Compra en una Tienda Virtual.**

Prioriza las historias utilizando MoSCoW.

Clasificaciones:

### MUST

Funcionalidad indispensable para que el MVP cumpla su objetivo.

### SHOULD

Funcionalidad importante que debería implementarse, pero el sistema podría funcionar sin ella.

### COULD

Funcionalidad deseable que puede implementarse si existe tiempo.

### WON'T

Funcionalidad que explícitamente no se implementará en esta versión.

Para cada historia indica:

* ID.
* Historia.
* Clasificación MoSCoW.
* Justificación.

La prioridad debe basarse en:

* Importancia para el objetivo del proyecto.
* Necesidad para el funcionamiento del MVP.
* Valor para el usuario.
* Dependencias entre funcionalidades.
* Complejidad.
* Tiempo disponible.

No clasifiques todo como MUST.

Finaliza con un resumen indicando cuántas historias quedaron en cada categoría.
