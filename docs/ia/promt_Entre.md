# Prompt — Entrevista simulada

Basándote exclusivamente en el proyecto:

**Análisis de Intención de Compra en una Tienda Virtual**

simula una entrevista entre un integrante del equipo de desarrollo y el stakeholder principal del proyecto.

IMPORTANTE:

La entrevista NO ocurrió realmente. Debe identificarse explícitamente como:

**ENTREVISTA SIMULADA**

Genera entre 15 y 20 preguntas relevantes.

Las preguntas deben investigar:

* Problema actual.
* Objetivo del proyecto.
* Usuarios del sistema.
* Datos disponibles.
* Información que se necesita analizar.
* Funcionalidades esperadas.
* Resultados esperados.
* Clasificación de intención de compra.
* Visualización de resultados.
* Reglas del sistema.
* Restricciones.
* Seguridad.
* Rendimiento.
* Usabilidad.
* Validación del modelo.
* Alcance del proyecto.
* Funcionalidades que NO deberían incluirse.

Para cada pregunta proporciona:

**Entrevistador:** pregunta.

**Stakeholder:** respuesta simulada.

Las respuestas deben ser coherentes con el proyecto y no introducir funcionalidades innecesarias.

Al finalizar, incluye una sección llamada:

## Hallazgos principales

Resume las necesidades y expectativas identificadas.

Entrega el resultado listo para:

docs/entrevista.md
