# Prompt — Transcripción de entrevista

Utiliza la entrevista simulada proporcionada y conviértela en una transcripción organizada.

IMPORTANTE:

La entrevista es SIMULADA y debe mantenerse identificada como tal.

Utiliza el siguiente formato:

**Entrevistador:** ...

**Stakeholder:** ...

Conserva el significado de las respuestas y no agregues información nueva.

Organiza la conversación de manera clara y profesional.

Al finalizar agrega:

## Observaciones de la entrevista

Incluye brevemente:

* Problemas identificados.
* Necesidades identificadas.
* Funcionalidades mencionadas.
* Restricciones mencionadas.
* Información que posteriormente debe convertirse en requisitos.

Entrega el resultado listo para:
