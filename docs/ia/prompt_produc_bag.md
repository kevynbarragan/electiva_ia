# Prompt — Product Backlog

Construye el Product Backlog del proyecto:

**Análisis de Intención de Compra en una Tienda Virtual.**

Utiliza exclusivamente las historias de usuario previamente definidas.

No agregues nuevas funcionalidades.

El Product Backlog debe contener:

| Orden | ID | Historia de usuario | Prioridad MoSCoW | Requisito relacionado | Criterios de aceptación |
| ----- | -- | ------------------- | ---------------- | --------------------- | ----------------------- |

Ordena las historias considerando:

1. Valor para el objetivo del proyecto.
2. Dependencias.
3. Necesidad para construir el MVP.
4. Prioridad MoSCoW.
5. Complejidad.

Las funcionalidades fundamentales de carga, validación, preparación y análisis de datos deben aparecer antes de las funcionalidades que dependen de ellas.

El entrenamiento y evaluación del modelo deben ocurrir antes de la clasificación final.

La visualización de resultados debe aparecer después de que existan resultados que visualizar.

No agregues:

* Épicas.
* Jira.
* MCP.
* Matriz de trazabilidad.
* Funcionalidades nuevas.
* Tareas técnicas.

El resultado debe representar el Product Backlog completo del MVP.

Entrega el resultado listo para:

docs/product-backlog.md
