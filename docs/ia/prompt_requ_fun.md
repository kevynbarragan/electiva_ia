# Prompt — Requisitos funcionales

Analiza:

1. El proyecto.
2. Los stakeholders.
3. La entrevista simulada.
4. La transcripción.
5. Los hallazgos identificados.

A partir de esta información identifica únicamente los requisitos funcionales del sistema.

Un requisito funcional debe describir algo que el sistema debe hacer.

Para cada requisito utiliza:

### RF-001 — [Nombre]

**Descripción:**

El sistema debe...

**Fuente:**

Indicar qué necesidad o parte de la entrevista lo justifica.

**Prioridad preliminar:**

Alta / Media / Baja.

Genera requisitos relacionados con aspectos como:

* Carga de datos.
* Validación de datos.
* Preparación de datos.
* Análisis exploratorio.
* Identificación de variables.
* Entrenamiento del modelo.
* Evaluación del modelo.
* Clasificación de intención de compra.
* Consulta de resultados.
* Visualización de resultados.
* Manejo de errores.

Solo incluye funcionalidades realmente justificadas por el proyecto.

No agregues:

* pagos,
* recomendaciones,
* aplicación móvil,
* comercio electrónico real,
* notificaciones avanzadas,
* funcionalidades administrativas innecesarias.

Evita duplicados.
