# Prompt — Identificación de stakeholders

Analiza el siguiente proyecto:

**Análisis de Intención de Compra en una Tienda Virtual.**

El sistema analizará datos del comportamiento de usuarios de una tienda virtual para identificar o estimar su intención de compra mediante análisis de datos y Machine Learning.

Identifica los stakeholders relevantes del proyecto.

Para cada stakeholder proporciona:

* ID
* Nombre o rol
* Tipo de stakeholder
* Relación con el proyecto
* Intereses
* Necesidades
* Expectativas
* Nivel de participación

Distingue claramente entre:

* Stakeholders directos.
* Stakeholders indirectos.
* Usuarios del sistema.
* Miembros del equipo de desarrollo.

No inventes organizaciones o personas específicas que no hayan sido proporcionadas.

Si un stakeholder es una suposición, indícalo claramente.

Finaliza explicando por qué cada stakeholder es relevante para el levantamiento de requisitos.

Entrega el resultado listo para guardarlo como:

docs/stakeholders.md
