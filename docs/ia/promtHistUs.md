# Prompt — Historias de usuario

A partir de:

* Stakeholders.
* Entrevista.
* Requisitos funcionales.
* Requisitos no funcionales.
* Alcance del proyecto.

crea las historias de usuario necesarias para el proyecto:

**Análisis de Intención de Compra en una Tienda Virtual.**

Utiliza exclusivamente este formato:

> Como [tipo de usuario], quiero [objetivo], para [beneficio].

Cada historia debe tener:

* ID.
* Título.
* Historia de usuario.
* Requisito relacionado.
* Descripción breve.

Ejemplo:

### HU-001 — Cargar dataset

**Historia:**

Como analista de datos, quiero cargar un dataset de comportamiento de usuarios, para poder realizar el análisis de intención de compra.

**Requisito relacionado:**

RF-001.

Reglas:

* No crear historias duplicadas.
* No crear historias para funcionalidades fuera del alcance.
* Cada historia debe representar una necesidad concreta.
* No escribir historias como tareas técnicas.
* Evitar historias demasiado grandes.
* Mantenerlas comprensibles para una persona no técnica.
* Utilizar actores reales del proyecto.
* No agregar épicas.
* No agregar tareas de desarrollo.
